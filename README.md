# 📌 Project Overview

AI FAQ Chatbot is an intelligent multi-domain chatbot built using:

- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Gemini AI API

The chatbot can answer user questions related to:

✅ College FAQs  
✅ HR Support  
✅ Customer Support  
✅ Product Assistance  

It also includes:

- 🔐 Authentication System
- 💬 Chat History
- 🧠 AI Responses
- 🎯 Domain-Based Suggestions
- 📱 Responsive UI

Suggestions automatically change based on selected domain.

| Domain | Suggestions |

| 🏢 HR Support | Leave, Payroll, Policies |
| 📦 Customer Support | Refund, Tracking |

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/ai-faq-chatbot.git
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv .venv
```

---

## 3️⃣ Activate Virtual Environment

### Windows

```bash
.venv\Scripts\activate
```

---

## 4️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

# 🔑 Environment Variables

Create `.env`

```env
SECRET_KEY=mysecretkey

GEMINI_API_KEY=your_gemini_api_key
```

---

# ▶️ Run Project

```bash
python app.py
```
